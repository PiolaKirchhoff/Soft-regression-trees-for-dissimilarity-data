# Generated datasets

This directory contains the CSV files produced by the notebooks in `dataset_generation/`.

Recommended structure:

```text
generated_datasets/
├── swiss_roll/
└── time_series/
    ├── covid/
    ├── flood1/
    ├── flood2/
    ├── flood3/
    ├── energy/
    └── iron/
```

The files in this directory are generated artifacts and should not be edited manually.
